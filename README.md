# Private Route — downloads

Finished programs of **Private Route** by [Lunazad Solutions](https://lunazad.com): a private route through your
own server, for Windows, Linux and Android. This page holds only the finished programs and the app's update feed
(`latest.json`), never the app's code.

- **Download:** open [the newest release](https://github.com/Moubasher82/private-route-releases/releases/latest)
  and pick `PrivateRoute.exe` (Windows), `PrivateRoute-linux` (Linux) or `PrivateRoute-android.apk` (Android).
- **Updates:** from version 0.3.0 the app checks here once a day and offers a newer version; nothing changes until
  you press Update. Every update is stamped with Lunazad's update key and checked against its fingerprint before
  it is used.
